# Портфолио Александры Невидиной

Статический одностраничный сайт: HTML, CSS и JavaScript без сборки и внешних зависимостей.

## Запуск

В этой папке выполните `node serve.mjs` и откройте http://127.0.0.1:4318/.
Для остановки сервера нажмите Ctrl+C.

## Публикация

Репозиторий: https://github.com/anevidina-bot/portfolio

В Settings → Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
Публичный адрес после успешного развёртывания: https://anevidina-bot.github.io/portfolio/
Файл `.nojekyll` отключает обработку Jekyll. Все пути к ресурсам относительные.

## Как обновлять

- Тексты разделов и контакты: `index.html`.
- Оформление: `styles.css`.
- Карточки курсов: массив `window.portfolioProjects` в `projects.js`. Скопируйте объект существующего курса и замените поля. Указывайте только готовые работы.
- Для нового локального курса создайте папку `courses/название/`, скопируйте в неё всю HTML-публикацию с исходной структурой и задайте `url: './courses/название/index.html'`.
- Обложки: `assets/`; фотография оптимизирована отдельно, оригиналы остаются в родительской папке и не публикуются.
- При изменении адреса сайта обновите абсолютный `og:image` в `index.html`.

На ширинах от 768 px курс открывается в диалоге с iframe, на телефонах — по обычной ссылке в новой вкладке. Отдельная ссылка всегда открывает новую вкладку. Iframe создаётся при нажатии и удаляется при закрытии. Escape закрывает диалог, фокус возвращается на ссылку запуска. Без JavaScript доступна прямая ссылка на курс.

В репозиторий не включаются исходное резюме и фотографии полного размера. Аналитика и формы не используются.
